Bookmark Cloud Sync

把 Chrome / ego(lite) 的书签双向同步到 Google Drive 私有空间（appDataFolder）。删除操作先存快照、再执行，支持一键回滚。

v1.0.0

首次配置（3 步）

  1. 在 Google Cloud Console 创建项目，启用 Google Drive API。
  2. 创建 OAuth 客户端：类型选「Web 应用」，重定向 URI 填下方显示的地址。
  3. 把 Client ID 填到下面，点「连接 Google 账号」。

作用域只需要 drive.appdata，只能读写本扩展自己的隐藏目录，看不到你网盘里的其它文件。
